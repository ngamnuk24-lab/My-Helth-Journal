MY HEALTH JOURNAL V3 — คู่มือเริ่มต้น

สิ่งที่เพิ่มใน V3:
1) ตั้งเวลาแจ้งเตือนการทานยาเป็นเวลา เช่น 08:00, 20:00 (คั่นด้วย comma)
2) ขอสิทธิ์ Notification และตรวจเวลาแจ้งเตือนขณะเปิดแอป
3) ปฏิทินประวัติการทานยา เลือกวันเพื่อดูรายการยาที่บันทึก
4) รายงานสุขภาพตามช่วงวันที่ รวมผลตรวจ ยาปัจจุบัน ประวัติทานยา นัดหมาย และค่าใช้จ่าย
5) ใช้เมนูพิมพ์ของ Safari/iPhone เพื่อบันทึกหรือแชร์เป็น PDF
6) รองรับไฟล์สำรองจาก V2 (ข้อมูลเดิม + รายการยาและประวัติ)

ติดตั้งบน iPhone:
- แตก ZIP แล้วนำไฟล์ขึ้นเว็บโฮสติ้งที่รองรับ HTTPS
- เปิด URL ผ่าน Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม
- แนะนำให้เปิดแอปผ่าน HTTPS เพื่อให้ฟังก์ชันติดตั้งและ Notification ทำงานได้ตามข้อจำกัดเบราว์เซอร์

ข้อจำกัดสำคัญ:
- การเตือนใน V3 ทำงานเฉพาะเมื่อหน้าแอปเปิดอยู่และระบบอนุญาต Notification
- ไม่รับประกันการเตือนเมื่อปิด Safari, ปิดแอป หรือ iPhone พักการทำงาน โปรดตั้งเตือนในแอป Reminders/นาฬิกาของ iPhone ควบคู่
- ข้อมูลเก็บใน Local Storage ของ Safari บนอุปกรณ์ ไม่ส่งไปเซิร์ฟเวอร์ ควรส่งออกไฟล์ JSON เป็นประจำ
- รายงาน PDF ใช้เมนูพิมพ์/บันทึก PDF ของ Safari
- แอปไม่แนะนำขนาดยา ไม่สั่งเริ่ม/หยุด/ปรับยา ให้ยึดตามแพทย์หรือเภสัชกร

ไฟล์หลัก: index.html, manifest.webmanifest, sw.js
